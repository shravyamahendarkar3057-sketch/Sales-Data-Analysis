# Sales Data Analysis

## Description

A simple Python data analysis project that analyzes sales data using Pandas. The project calculates total sales, total revenue, sales by category, best-selling product, and highest-revenue product.

## Features

- Load sales data from a CSV file
- Calculate total sales for each product
- Calculate total revenue
- Analyze sales by category
- Find the best-selling product
- Find the product with the highest revenue
- Visualize sales by category using a bar chart

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## Project Files

- `Sales_data.csv` - Sales dataset
- `sales_analysis.py` - Python analysis program
- `sales_by_category.png` - Sales by category visualization
